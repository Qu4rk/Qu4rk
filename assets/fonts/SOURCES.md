# Font sources

Chillax Medium was already present in this profile repository. Satoshi Regular was obtained from the same Fontshare API used by the QuarkMade website. Both families are by the Indian Type Foundry.

- [Satoshi](https://www.fontshare.com/fonts/satoshi)
- [Chillax](https://www.fontshare.com/fonts/chillax)
- [Fontshare licensing](https://www.fontshare.com/licenses)

The SVG generator outlines display typography; visitors do not download these font files when viewing the README.
